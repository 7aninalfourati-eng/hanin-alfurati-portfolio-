سياسة الخصوصيةPrivacy Policy

آخر تحديث: سبتمبر 2026Last updated: September 2026

سرية بيانات العملاءClient Data Confidentiality

يتم التعامل مع بيانات العملاء بسرية تامة، ولا تتم مشاركتها مع أي طرف غير مصرح له تحت أي ظرف.Client data is treated with full confidentiality and is never shared with any unauthorized party.

الاستخدام في معرض الأعمالUse in the Portfolio

  • لا تُستخدم بيانات أي عميل في معرض الأعمال (Portfolio) دون موافقة مكتوبة صريحة.Client data is never used in the portfolio without explicit written consent.
  • عند عرض نماذج مشاريع، تُستخدم بيانات مجهولة الهوية فقط.Anonymized/sample data only is used when showcasing project examples.
  • يمكن توقيع اتفاقية عدم إفصاح (NDA) بناءً على طلب العميل.A Non-Disclosure Agreement (NDA) can be signed upon client request.

حفظ الملفات ومدة الاحتفاظFile Storage & Retention

  • يتم تحديد طريقة حفظ الملفات ومدة الاحتفاظ بها ضمن الاتفاق مع كل عميل.The storage method and retention period are defined in the agreement with each client.
  • يتم حذف الملفات أو إعادتها للعميل بعد انتهاء المشروع، حسب ما يتم الاتفاق عليه.Files are deleted or returned to the client after project completion, as agreed.
  • الأشخاص المخوّلون بالوصول إلى بيانات المشروع هم فقط من تتم الموافقة عليهم صراحة ضمن نطاق العمل.Only individuals explicitly approved within the project scope may access project data.

عدم رفع بيانات العملاء إلى GitHubNo Client Data on GitHub

هذا الموقع منشور على GitHub Pages، ولذلك لا تُرفع أي بيانات عملاء حقيقية أو حساسة إلى مستودع الموقع بأي شكل، بما في ذلك داخل صور المشاريع المعروضة.This site is hosted on GitHub Pages, so no real or sensitive client data is ever uploaded to the repository, including within project screenshots.

نموذج طلب الخدمةService Request Form

لحماية بياناتكم، يُرجى عدم إرسال أي ملفات أو معلومات سرية قبل تأكيد نطاق المشروع والاتفاق على قناة آمنة لنقل البيانات. نموذج الطلب في هذا الموقع يجمع معلومات الطلب الأساسية فقط؛ بعد قبول المشروع يتم إرسال رابط آمن ومنفصل لاستلام البيانات.To protect your data, please do not send confidential files before the project scope is confirmed and a secure transfer method is agreed upon. This site's request form collects only basic request information; after the project is accepted, a separate secure link is shared for data transfer.

لأي استفسار حول هذه السياسة، يُرجى التواصل عبر البريد الإلكتروني الموضح في صفحة التواصل.For any question about this policy, please reach out via the email listed on the contact page.
